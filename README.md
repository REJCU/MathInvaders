# MathInvaders

A space invaders styled math game, where players control a spaceship to shoot descending aliens and asteroids labeled with math problems (or solutions).
Aim to destroy before they hit your ship and to get the highest score.

## Features

- **Difficulty Options:** Easy, medium and hard that alters the game parameters (equations, speed, spawn rates)
- **Activity Screen:** Canvas game loop, SVG rendering for sprites, Life/score tracking. Unlimited Life practice mode for low-pressure learners.
- **Settings Screen:** Audio preferences. Low spec mode toggle disabling expensive background rendering and particle effects to support budget or older hardware.
- **Leaderboard:** Displays high scores. Global Leaderboard (Maybe)

## Tech Stack
- UI Framework: Jetpack Compose (Material Design 3)
- Database: Room DB for local, secure user statistic persistence
- Networking: Retrofit / Ktor (Maybe)
